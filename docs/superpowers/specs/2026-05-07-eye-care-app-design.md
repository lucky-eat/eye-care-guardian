# 护眼小卫士 — 设计规格文档

## 概述

一款 Android 护眼提醒应用。用户设定时长（20/30/45分钟或自定义），到时全屏提醒休息眼睛并引导做眼保健操。采用 Capacitor.js（HTML/CSS/JS + 原生壳）构建，输出 .apk 安装包。

## 功能列表

### 1. 计时器

- 4个预设卡片：20分钟（轻度）、30分钟（推荐，高亮）、45分钟（重度）、自定义（弹出时间选择器）
- 大圆环倒计时动画（橙暖色调环形进度条）
- 暂停 / 继续 / 重置
- "我休息了"按钮：点击后重置计时器，记录休息次数

### 2. 到时提醒

- 全屏弹窗：暖橙色渐变背景，脉冲动画闹钟图标
- 护眼小练习引导文案（4步）
- 按钮：延期5分钟 / 我休息好了（重置计时）
- 通知栏通知：简洁消息，自动同步至华为手表（蓝牙通知转发）
- 振动：自定义次数（默认3次），可设为 1-N 次 或持续振动
- 声音：可选开关

### 3. 紧急静音

提醒触发后，任一操作立即停止声音和振动：
- 点击屏幕任意位置
- 按音量键
- 翻转手机（屏幕朝下）

### 4. 提醒方式设置

- 仅振动 / 仅声音 / 声音+振动（三选一）
- 振动次数自定义：默认3次，用户可输入 1-10 之间的数字

### 5. 免打扰模式

- 总开关
- 自定义静音时段（开始时间 - 结束时间）
- 3个快捷场景：今晚免打扰（到明早8点）、午休免打扰（12:00-13:30）、观影模式（暂停2小时）

### 6. 护眼小贴士

- 主界面顶部区域，每次显示一条随机护眼知识
- 内容池包括：20-20-20法则、眨眼提醒、坐姿提醒等

### 7. 统计

- 今日休息次数（顶部标签）
- 累计休息次数（本地存储）

### 8. 每日启动提醒

- **定时启动**：每天固定时间弹通知"新的一天，点击启动护眼计划"，用户点击后当天计时器开始工作
- **智能检测启动**：检测到解锁屏幕 + 持续使用超过 1 分钟 → 通知询问"检测到你在用手机，需要启动护眼吗？"
- 通知栏快捷操作按钮：`暂不` / `启动`，无需进入 App
- 未启动时，当天不触发任何休息提醒

## 技术方案

| 项 | 选型 |
|---|---|
| UI层 | HTML5 + CSS3 + Vanilla JS |
| 原生壳 | Capacitor.js 6.x |
| 后台计时 | Capacitor Background Task 插件 |
| 本地通知 | Capacitor Local Notifications 插件 |
| 振动 | Capacitor Haptics 插件 |
| 音量键事件 | Capacitor 键盘事件 + Android volume key listener |
| 设备方向 | Device Orientation API（检测翻转） |
| 本地存储 | localStorage |
| 打包输出 | Android APK（Gradle 构建） |

## 数据流

```
用户选择时长 → 启动计时器 → 倒计时运行
                                ↓
                          时间到 → 触发提醒
                                    ↓
                    全屏弹窗 + 通知 + 声音/振动
                                    ↓
                    用户操作（点击屏幕/音量键/翻转）→ 立即静音
                                    ↓
                    用户点击"我休息好了"→ 重置 → 休息次数+1
                    用户点击"延期"→ 加5分钟重新计时
```

## 边界条件

- 计时器到0后不自动重置，必须用户交互
- 免打扰时段内，计时器依旧运行但不触发提醒
- 自定义时长范围：1-120分钟
- 振动次数范围：1-10次
- 手机重启后计时器不保留（设计选择：简洁优先）
- 翻转检测仅在提醒弹窗显示时生效
